Backups

Your database is backed up automatically every time the app starts, whenever something changed since the last backup - nothing to remember. The newest {{ keep }} automatic backups are kept. Backups made with the button, and those made before an upgrade changes the database, are never deleted.

Backups are complete copies, including what a CSV doesn't hold (reports, categories), saved to {{ backup_dir }}. They're on the same disk as the app: they protect against mistakes and a damaged database, not against the disk failing. For that, the folder can be a synced one (e.g. Dropbox) - set BLOODTRACKER_BACKUP_DIR when starting the app.

{% include "partials/backups.html" %}
How to restore a backup
  1. Stop the app: Ctrl+C in the terminal where it runs.
  2. Copy the backup over your database:
    cp "{{ backup_dir }}/BACKUP_NAME.db" "{{ db_path }}"
  3. Start the app again.

Tip: back up first, so you can undo the restore too.
